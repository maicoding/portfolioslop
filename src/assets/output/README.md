Lege hier lokale Medien fuer die Sektion `Tools_and_Output` ab.

Ordnerstruktur:
- `images/` fuer statische oder animierte Bilddateien
- `videos/` fuer kurze Video-Loops, Screen-Captures oder Render-Fragmente

Unterstuetzte Bildtypen:
- `.png`
- `.jpg`
- `.jpeg`
- `.webp`
- `.avif`
- `.gif`
- `.svg`

Unterstuetzte Videotypen:
- `.mp4`
- `.webm`
- `.ogg`
- `.mov`
- `.m4v`

Die Seite zieht bei jedem Aufruf zufaelliges Material aus diesen Unterordnern.
Wenn keine Videos vorhanden sind, erscheint absichtlich eine kaputte `NO_SIGNAL`-Kachel.
