Lege hier eigene `.glb` oder `.gltf` Modelle fuer den 3D-Hintergrund ab.

Die alte Primitive-Logik bleibt erhalten.
Vorhandene Modelle werden nur teilweise zugemischt und ersetzen die alten Objekte nicht komplett.

Empfehlungen:
- eher leichte Modelle
- moeglichst zentriert exportieren
- idealerweise ohne riesige Animationen
- Dateitypen: `.glb`, `.gltf`
